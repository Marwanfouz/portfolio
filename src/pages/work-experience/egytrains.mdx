### Project Overview

Contributed to the **EgyTrains** web platform delivering schedules, routes, and train information for Egypt. Focused on **SEO, performance, and user experience** improvements.

### Key Features

- Improved SEO with semantic HTML, structured metadata, and optimized meta tags → boosted search visibility by ~30%.
- Enhanced performance with image optimization, code splitting, and Next.js caching → reduced load time **3.2s → 1.4s (55% faster)**.
- Integrated **PWA** using Serwist for offline support and faster reloads.
- Implemented **`react-window`** for smooth rendering of long timetable lists.
- Added automated sitemap and robots.txt with **`next-sitemap`**.
- Worked closely with Ahmed Hany (Senior Software Engineer & Project Owner) <a href="https://www.linkedin.com/in/dev-ahmedhany/" target="_blank" rel="noreferrer">LinkedIn</a>.
