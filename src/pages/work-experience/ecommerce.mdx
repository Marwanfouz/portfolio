### Key Features

- Built and deployed a responsive e-commerce platform with catalog, product detail, cart, secure checkout, and admin dashboard.
- Stack: **Next.js 15**, **TypeScript**, **Shadcn/ui**, **Firebase** (Auth/Firestore), **Supabase Storage** for media.

### Technologies Used

- **Next.js 15** (App Router, Server Components, ISR) for performance and SEO.
- **TypeScript** for type safety and enhanced developer experience.
- **Shadcn/ui** for responsive and consistent UI components.
- **Firebase** (Auth, Firestore) for authentication, roles, and real-time data.
- **Supabase Storage** for product media and CDN delivery.
- **PWA**: service worker, web manifest, caching strategies, push notifications.
- **Analytics**: Microsoft Clarity session insights + Firebase Analytics events.
